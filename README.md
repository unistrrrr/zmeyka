# Изгиб Питона

Классическая «Змейка» на Python и Pygame. Управляйте стрелками,
собирайте яблоки и избегайте столкновения с собственным телом.
При выходе за край поля змейка появляется с противоположной стороны.

## Запуск

В корне проекта установите зависимости и запустите игру.

```bash
python -m pip install -r requirements.txt
python the_snake.py
```

Проверить проект можно командами `python -m pytest` и
`python -m flake8 the_snake.py`.
