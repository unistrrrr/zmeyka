# Змейка

## Правила

- Змейка движется непрерывно. Направление меняется стрелками, разворот на 180° запрещён.
- Каждое яблоко увеличивает длину змейки на одну клетку.
- При выходе за границу поля змейка появляется с противоположной стороны.
- При столкновении с собственным телом игра начинается заново.
